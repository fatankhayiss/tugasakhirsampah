================================================================
DIAGRAM 1: LOGIN
================================================================

flowchart TD
    A((Start))
    A --> B[Admin membuka halaman Login]
    B --> C[Sistem menampilkan form Login]
    C --> D[Admin mengisi username dan password]
    D --> E[Admin mengklik tombol Login]
    E --> F{Metode POST valid?}
    F -->|Tidak| G[Sistem menampilkan pesan kesalahan metode]
    G --> H((End))
    F -->|Ya| I{Kolom username dan password kosong?}
    I -->|Ya| J[Sistem menampilkan pesan kolom tidak boleh kosong]
    J --> C
    I -->|Tidak| K[Sistem melakukan query data pengguna ke database]
    K --> L{Username ditemukan?}
    L -->|Tidak| M[Sistem menampilkan pesan username atau password salah]
    M --> C
    L -->|Ya| N{Password cocok dengan hash?}
    N -->|Tidak| M
    N -->|Ya| O{Level pengguna adalah admin?}
    O -->|Tidak| P[Sistem menampilkan pesan bukan admin]
    P --> C
    O -->|Ya| Q[Sistem menyimpan data sesi pengguna]
    Q --> R[Sistem mengarahkan ke halaman Dashboard]
    R --> S[Sistem menampilkan Dashboard Admin]
    S --> H
