Dokumentasi Skripsi | Format: Mermaid Graph
====================================================

CARA RENDER:
1. Copy semua kode di bawah (mulai dari "graph LR" sampai baris terakhir tanda ```)
2. Buka https://mermaid.live
3. Paste ke editor, diagram akan otomatis muncul
4. Klik tombol "Download SVG" atau "Download PNG" untuk menyimpan gambar

CATATAN:
- Aktor  : Admin (satu-satunya aktor di web)
- <<include>> : Use case yang SELALU dijalankan sebagai bagian dari use case lain
- <<extend>>  : Use case yang OPSIONAL, hanya dijalankan pada kondisi tertentu
- Garis lurus (---) : Asosiasi antara aktor dan use case
- Garis putus (-.->): Relasi include atau extend antar use case
