Dokumentasi Skripsi | Format Swimlane UML
Aktor: Admin dan Sistem (2 swimlane)
====================================================

CARA RENDER:
1. Copy kode Mermaid di antara tanda ``` (tidak termasuk tanda ```)
2. Buka https://mermaid.live
3. Paste ke editor, diagram akan otomatis muncul
4. Download SVG atau PNG untuk laporan skripsi

CATATAN SWIMLANE:
- subgraph Admin  => lane kiri / atas  (aksi dilakukan Admin)
- subgraph Sistem => lane kanan / bawah (respon otomatis Sistem)
- Panah antar subgraph menunjukkan perpindahan alur antar aktor
- Decision diamond ({}): titik keputusan dengan cabang Ya/Tidak
- Start : ([Start]) | End : ([End])
